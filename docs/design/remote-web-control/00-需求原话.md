# 注释（非原文）

## 背景（主代理调研结论，2026-10-08）

- omp collab 同样是 relay 架构（默认 `wss://my.omp.sh` 官方托管，Go 实现，不开源）；其"简单"来自官方公共 relay 免搭建 + relay 直接托管 web 客户端 + AES-256-GCM E2E（key 只在 URL fragment，持链接即权限）。
- remote_pi 是 Ed25519 身份 mesh + owner-key 签名会员制 + 跨 PC 路由 + 原生 APK；无 web 客户端，APK 在用户的安卓 13 / MIUI 14 上无法安装，因此整体不可用。
- 本设计采用直连模式：浏览器经 WebSocket 直连 TUI 进程，无 relay。外网可达性由用户自选隧道（cloudflared / tailscale 等）解决，不属于本功能范围。

## 效果清单（可验收的功能效果）

1. **E1** 在 pi 交互式 TUI 内一条命令（`/remote`）开启远程分享，立即得到一个 web 链接（含局域网地址提示与二维码）。
2. **E2** 任意现代浏览器（明确目标：安卓 13 / MIUI 14 自带浏览器与 Chrome）打开链接，无需安装任何东西，即可实时查看正在运行的会话：流式 assistant 文本、thinking、工具调用卡片、用户消息、排队消息。
3. **E3** 浏览器端可以发送 prompt、turn 进行中 steer、中断（abort）——即用户原话"直接控制进程"。
4. **E4** 直连架构：无 relay、无第三方服务依赖；host 主动监听，浏览器直接连接。
5. **E5** 链接即权限：token 一次性生成、仅存内存，`/remote stop` 立即失效。
6. **E6** TUI 与浏览器同时操作同一会话：TUI 不中断、不降级；web 端与会话切换（/new、/resume）自动跟随。
7. **E7** 服务关闭（stop / TUI 退出）后端口释放、token 失效、进程无残留。

## 解法清单（用户提议或已拍板的候选方案及前提核验）

1. **S1 直连模式**（用户拍板："好，那你就做直连模式吧"）。
   - 前提核验：`PiServerListener` 抽象支持任意有序字节连接，README 明确预留 WebSocket listener 认证位（`packages/server/src/listener.ts:4-10`、`packages/server/README.md`）；通过。
2. **S2 复用 pi-server / pi-client / pi-protocol 参与者协议栈**（主代理建议，用户认可大方向；不做 relay、不自造新协议）。
   - 前提核验：`pi-protocol` CBOR + framing 为纯 `Uint8Array` 实现、无 Node 依赖（`packages/protocol/src/framing.ts:1-30`，`src/cbor/`）；`pi-client` 声明无 Node 专属导入（`packages/client/README.md`）；`CodingAgentRuntime` 已验证"任意 AgentSession → PiSessionRuntime"适配路径（`packages/coding-agent/src/server/coding-agent-server.ts:368-397`）；通过。
3. **S3 命令名 `/remote`**（用户提名；理由：`/share` 已被 GitHub gist 分享占用（`packages/coding-agent/src/commands/builtins.ts:737`），`/collab` 不符合语境）。
   - 前提核验：全仓无 `/remote` 命令冲突（`builtins.ts`、`slash-commands.ts` 检索无命中）；通过。
4. **S4 外网穿透不在范围内**（用户已理解直连模式的边界：局域网直用，外网自配隧道）。
5. **S5 web 客户端随 host 进程分发**（静态文件内嵌于 pi 安装产物，host 直接 serve）。
   - 前提核验：coding-agent 已有 `copy-assets` 静态资源复制模式（`packages/coding-agent/package.json` scripts）；通过。
